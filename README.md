# EquiShare

EquiShare è un'app Android per dividere facilmente le spese tra gruppi 
di amici, coinquilini o colleghi. Traccia le spese condivise, calcola 
i debiti automaticamente e mostra statistiche e attività del gruppo.

Funzionalità principali:
- Gestione gruppi e spese condivise
- Calcolo automatico dei debiti
- Caricamento scontrini tramite fotocamera
- Grafici e statistiche sulle spese
- Notifiche push in tempo reale
- Accesso con Google o email

## Download e installazione

1. Vai alla pagina [Releases](https://github.com/GreppiFilippo/EquiShare/releases/latest)
2. Scarica il file `EquiShare-v1.0.apk`
3. Sul tuo dispositivo Android, apri il file APK
4. Se richiesto, abilita **"Installa da fonti sconosciute"** nelle impostazioni
5. Segui le istruzioni a schermo per completare l'installazione
